## Project Overview

A simulated enterprise network infrastructure connecting a corporate headquarters and a remote branch office.

The project demonstrates enterprise network design, VLAN segmentation, dynamic routing, network redundancy, secure administration, access control and centralised Syslog monitoring.

## Network Architecture

The simulated environment includes:

- Headquarters and remote branch network.
- Cisco routers and multilayer switches.
- Redundant headquarters core switches.
- Departmental VLANs.
- Centralised DHCP, DNS and web services.
- Dedicated SOC server for Syslog collection.

## Technologies

- Cisco Packet Tracer
- Cisco IOS CLI
- VLANs and inter-VLAN routing
- OSPF
- HSRP
- DHCP and DNS
- Extended ACLs
- Port Security
- SSH Version 2
- Syslog
